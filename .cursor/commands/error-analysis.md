***ERROR-ANALYSIS Command Protocol**
**Objective:** Conduct comprehensive error analysis of user-provided input to enable precise error resolution.
**Input Requirements:**
- User must provide: code files, error messages, system logs, or specific error descriptions
- Specify programming language, framework, and environment details
- Include steps that led to the error
**Analysis Protocol:**
**Phase 1: Error Identification**
- Catalog all error types (syntax, runtime, logical, compilation)
- Extract exact error messages and line numbers
- Identify error severity levels (critical, major, minor)
**Phase 2: Root Cause Analysis**
- Trace error origins through code flow
- Identify contributing factors and dependencies
- Map error propagation patterns
- Analyze environmental or configuration issues
**Phase 3: Impact Assessment**
- Determine affected system components
- Assess data integrity risks
- Evaluate performance implications
- Identify security vulnerabilities if present
**Deliverables:**
1. **Error Summary Table:** Type, location, severity, description
2. **Root Cause Report:** Primary and secondary causes with evidence
3. **Code Analysis:** Problematic code segments with line references
4. **Fix Recommendations:** Specific, actionable solutions ranked by priority
5. **Prevention Guidelines:** Best practices to avoid similar errors
**Output Format:** Structured technical report with clear sections, code examples, and implementation steps for each recommended fix.***
