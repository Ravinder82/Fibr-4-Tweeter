## Technical Specifications

### Color Palette
- **Primary Background**: `#ffffff` (pure white)
- **Secondary Background**: `#f5f5f5` (light grey)
- **Text Primary**: `#000000` (pure black)
- **Text Secondary**: `#666666` (medium grey)
- **Accent Colors**: `#404040`, `#666666`, `#888888` (grey spectrum)

### Design Elements
- **Glassmorphism**: Backdrop blur (20px), transparency gradients
- **Neumorphism**: Inner shadows, embossed effects
- **Typography**: System fonts, 21:1 contrast ratio
- **Shadows**: Consistent elevation system (sm/md/lg)

### Key Features to Highlight
- **AI Integration**: Google Gemini 2.0 Flash API
- **Tone System**: 11 presets with custom mixing
- **Quick Actions**: 5 one-tap generation modes
- **Content Types**: Posts, threads, replies, comments
- **Gallery System**: 50-item limit with virtual scrolling
- **Privacy Focus**: Local storage, direct API calls

## Usage Instructions

1. **Generate Images**: Use these prompts with AI image generation tools (Midjourney, DALL-E, Stable Diffusion)
2. **Maintain Consistency**: Ensure all images use the exact black/white monochrome theme
3. **Quality Check**: Verify glassmorphism effects, neumorphic depth, and typography clarity
4. **Chrome Web Store**: Upload to developer dashboard in specified formats and sizes
5. **Backup**: Keep original prompts for future updates or revisions
